# Activation codes – retired in 1.28

Since S-ERP 1.28 a business activates S-ERP itself with its **My Wallet agent number and password**: during set-up or under *Settings → Activation*. Once that is done there is no trial, no code and no expiry date.

`make-code.js` is kept only for reference. Installations that were activated with a code stay activated, and their end dates no longer apply.
